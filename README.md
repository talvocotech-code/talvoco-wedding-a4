# Talvoco UK wedding invitation template A4

Talvoco UK wedding invitation template A4 - demo with fictional names, dates and venues.

- Live demo: https://talvoco-wedding-a4.vercel.app/
- Built with Vite + React + TypeScript. Run locally: `npm install && npm run dev`; production build: `npm run build`
- All content lives in `src/data/invite.ts` (demo values: replace per customer).
- Music: "Gymnopedie No. 2" by Kevin MacLeod (incompetech.com) - CC BY 4.0, see `MUSIC-LICENSES.md`.
- Crafted by [Talvoco](https://talvoco.com)
